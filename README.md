# Notes API — сервис для управления заметками

## Описание проекта

Это REST API для создания, чтения, обновления и удаления заметок.  
Проект разработан в рамках учебной практики для демонстрации навыков веб-разработки на Python.

**Стек технологий:**
- Python 3.14
- Flask (веб-фреймворк)
- SQLAlchemy (ORM)
- SQLite (база данных, используется для деплоя)
- PostgreSQL (использовался локально)
- Gunicorn (сервер для деплоя)
- Docker (контейнеризация)
- Pytest (тестирование)

---

## API Эндпоинты

| Метод | URL | Описание |
|-------|-----|----------|
| `GET` | `/notes` | Получить список всех заметок |
| `GET` | `/notes/<id>` | Получить заметку по ID |
| `POST` | `/notes` | Создать новую заметку |
| `PUT` | `/notes/<id>` | Обновить существующую заметку |
| `DELETE` | `/notes/<id>` | Удалить заметку |
