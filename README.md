# Практика: Обработчик логов
## Описание проекта
Скрипт для анализа лог-файлов. Читает файл `sample.log`, находит строки с ошибками и выводит их количество. Реализованы две версии: медленная (с вложенными циклами) и быстрая (с оптимизацией).
